# K3.2.2 — Structural file memory

A conventional file exposes its logical bytes, length and access permissions independent of physical backing. RVFile retains stable object identity during changes of representation; open descriptions and local descriptors are unchanged. The freestanding and hosted targets share this implementation.

Each 4 KiB page has a tag: zero (implicit all-zero), 1..16 (exact short period) or 255 (exclusive dense pool slot). For a candidate period d the admission predicate is B[i] == B[i-d] for every d <= i < 4096. A zero page is checked first. The first admitted period is retained, otherwise all bytes are stored densely. For an admitted period byte observation is pattern[i mod d]. This is exact finite-page representation, not inference about unobserved bytes or arbitrary compression.

A partial write reconstructs the affected page in a bounded scratch buffer, overwrites the selected range and admits a new representation. Full-page writes admit directly. A changed page can become dense and a repaired page can become periodic again. Truncation and unlink release dense slots and reset page tags. Unwritten gaps and hidden tails are zero. An oversized write is refused before mutation. The invariant is one exclusive dense slot per dense page; 512 possible pages and 512 slots ensure dense fallback for the entire eight-file, 256-KiB-per-file namespace. Fixed-capacity pool reservation still exists in BSS; no claim of smaller reserved or measured resident RAM, arbitrary sharing of dense pages, or faster execution. Worst-case admission scans up to 16 candidate periods per page, plus zero check and reconstruction; this is a correctness-first representation policy.

## Persistent format

vlk elf --compact-volume PATH ELF [ARG...] writes VLKFS2; --volume PATH writes VLKFS1 for existing consumers. Both read either format. Same 8-byte magic (VLKFS2 plus two NULs or VLKFS1), repeated name-length u8, logical size u32 little endian, name bytes. V1 stores logical file bytes. V2 stores each logical page with one tag byte, then no data for zero, d pattern bytes for tag d=1..16, or exactly min(4096, remaining logical bytes) for tag 255. Loader reconstructs logical bytes and independently re-admits pages; it accepts nonminimal valid encodings. Final-page hidden tail is restored as zero. Invalid tags, truncation, duplicate names, oversized lengths are rejected. Output uses the existing lock, temporary file, fsync and rename on successful guest exit; no new directory fsync, authenticity, checksum, or power-loss guarantee. No guest path forwarding. Reading with a different output option converts the volume upon successful exit. Dense data can grow by one byte per page in V2.

## Executed evidence

make all boot plus filter, abi, runtime and descriptor targets built. tests/structural_files.py ran via dist/vlk run. Native eager oracle: 5,000 randomized mixed writes, reads, clears, periodic and random data, across eight files; full content and ownership checks every 100 operations; 512 dense slots filled and verified, 64 reclaimed by zero overwrite, all reclaimed on clear. Duplicated descriptor shared-offset mutation and repair moved one page from period 7 to dense and back to period 7 with unchanged file identity. Existing compiled RV32 file utility wrote 262,144 periodic bytes through ordinary syscalls. V1 file size 262,164 bytes; V2 532 bytes (64 tags and seven bytes per page plus file framing). A separate invocation read the exact original data; a one-byte mutation materialized one page while 63 remained periodic. XOR transform, random dense fallback, sparse seek holes, V2 -> V1 -> V2 conversion, failed guest rollback and five malformed V2 cases passed. Independent Python parser reconstructed contents. No timing claim or general compression ratio.

Prior descriptor regression (two guests, 55 scheduling rounds), runtime (16 invocations), negative ELF (8 malformed and 4 traps), filesystem (16 native/guest comparisons, 196 KiB transform, eight restarts) passed via VL-K. Combined invocation timed out before filesystem completed; filesystem passed separately. Static i386 Multiboot image 50,636 bytes, no unresolved symbols; QEMU boot unverified. No fresh full regression or standard libc qualification claimed.

## Next

Generalize the same exact byte-object contract to address spaces and copy-on-write immutable backing; investigate sparse overlays so an isolated change need not materialize a whole page. Separate descriptive cost from observation and mutation cost; retain dense fallback and qualify on externally developed applications. Progress standard libc, process scheduler and real boot independently. This is a structural representation behind an unchanged conventional interface, not a substitute for ABI compatibility.
