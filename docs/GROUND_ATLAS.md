## Admitted domain

One u32 register, 1..64 instructions drawn from set/add/mul literal and self-mulr (square), observed modulo 2^b for 1<=b<=12. These integer operations commute with reduction modulo 2^b, including the source's modulo 2^32 wraparound. The projection preserves the requested low bits for every full-width seed and every u64 iteration count, not the erased high bits or arbitrary register programs. Admission binds version, exact ordered source program and projection width via SHA256. No arbitrary code execution from atlas data; locally defined opcode semantics only.

Explicit discover(kernel,program,bits) obtains one actual reference WASM observation per residue, compares against independently implemented BigInt source semantics, and admits a complete finite transition table. This is exhaustive finite-domain qualification, not black-box inference of a universal nonlinear law or automatic discovery from application traces. Source observations are not retained as a separate evidence log. The saved JSON contains the source, geometry and transition table; reopen independently rechecks every transition and rebuilds the jump powers, without needing WASM. Persistence uses a temporary file and rename; no fsync, crash durability, concurrent writer or authenticated provenance guarantee. A valid but different source/table has a different key, not authorization for that source. Caller must supply the intended domain/program. No arbitrary code or native source provenance is authenticated by the key.

## Realization

For N=2^b and T(x)=projected transition, build J_0(x)=T(x), J_(k+1)(x)=J_k(J_k(x)) for 0<=k<63. A u64 query uses at most 64 selected jumps and the local admission function checks the ordered hop witness against the private, derived jump tables. This is not an independent portable proof of a table's provenance. Reopen revalidates the table against the source semantics, and the independent test oracle uses cycle detection instead of binary lifting. Initial discovery costs N source evaluations and O(N*program length) verification; index preparation and memory cost O(64N). One 4096-state law uses 524288 bytes of typed-array jump payload plus JS table/metadata. Saved JSON excludes the jump index. No compression of full machine state or general complexity bound.

Dispatcher binding wasm-reference-residue reserves 2*steps*program_length+1 units (reference and scalar verification allowance) with source work ceiling one million. The atlas candidate reserves 130 modeled units for up to 64 jumps and their checks, plus separate dispatcher probe charges. Units are not measured wall time or physical operations; preparation and reload costs are not charged per request. For short coordinates reference can win; for large coordinates atlas wins only if the exact source/projection is present. Unknown source outside reference budget refuses. At most 16 laws, 512 KiB persisted input. No cost learning, autonomous discovery trigger, remote atlas, effectful operations or Linux integration yet.
