# C0.11 — Layered contracting Grounds

Restricted constructive case of the Layered Path Ground Conjecture. A source-described nonlinear, piecewise deterministic u32 transition uses two register programs selected by the current low bit. Each consists of 1..64 set/add/mul literals and self-mulr (square). The selector is a host-level composition of actual original WASM register programs; it is not a Linux branch instruction or arbitrary program compiler. Supports projected low b bits, 1<=b<=32, and u64 iteration count. Reuses the original WASM source reference and common realization dispatcher. New algebraic compiler is original VL-K code; no external module imported in this pass. Finite GroundAtlas remains available in its own domain.

## Proof

For residues x=y mod 2^k, k>=1, their parity selectors agree. Each admitted instruction is congruence-preserving. Addition gives no guaranteed extra bits; multiplication by m gives v2(m) extra bits; squaring gives at least one because x^2-y^2=(x-y)(x+y), and x+y is even. Set and zero multiplication erase the difference. Sum conservative gains along the chosen layer, capped at 32 (u32 modulus). Composition retains at least that gain. This holds for every pair in the admitted domain, not inferred from samples.

The selector graph has exactly two parity states; each source layer defines a deterministic parity transition. For each starting parity let d be the tail length, p the selector cycle length, g the summed gain around the cycle. Compare trajectories at d and d+p: parity agrees. After j complete selector cycles the states at those two phase-aligned times agree modulo 2^min(b,1+j*g). Thus if g>0, S=d+p*ceil((b-1)/g) suffices for f^S(x)=f^(S+p)(x) modulo 2^b. Closure extends equality to all later times. Realize n<S directly; otherwise use S+(n-S) mod p. For b=1 use S=d even without contraction. For b>1 and g=0 refuse this Ground for that starting parity; this is not an impossibility proof for other methods. Tail d<=1, period p<=2, so max reduced coordinate <=63 for b=32 (d=0 if p=2). No table over 2^b states, and no long orbit replay. Proof depends on the declared instruction semantics; implementation cross-checks against WASM, not an independently formalized proof of WASM or native machine code. The same bound uses O(b) layer executions for variable b; no universal constant complexity claim.

## Implementation

compileLayered returns a source digest, projection, frozen source layers and two-state parity/gain/path certificate; the translation/square example serializes to 289 JSON bytes, not executable size or full resident memory. No persisted atlas admission or automatic discovery yet; bindings reconstruct the small plan from source for each query. Admission independently computes parity and reduced trajectory using BigInt source semantics, sharing the structural bound calculation. The test oracle instead lifts a fixed point of the cycle composition one bit at a time, and independently checks small-domain trajectories by explicit orbit tracing. Source hash binds exact syntax and domain; not authorization. Receiver-owned bindings and immutable factory intentions are required.

Reference binding selects one actual WASM reference invocation per step; admitted results compare against separate BigInt iteration. Ground binding uses bounded Math.imul arithmetic and BigInt verification of the reduced trajectory. Dispatcher reserves 2*steps*max layer length+1 for reference (source work ceiling one million) and 2*reduced steps*max layer length+5 for Ground, plus dispatcher probe charges. Model units omit setup, source hashing, and repeated plan construction; not measured resources, actual machine instruction counts, or a wall deadline. Noncontracting full-width intents outside reference budget refuse; independent affine or finite methods are not automatically translated into this domain. No arbitrary source instructions, dynamic side effects, multidimensional laws or live Linux integration.
