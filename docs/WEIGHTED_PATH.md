# K2.5 — Weighted temporal Grounds and pure-loop receipts

A countdown loop with two forward affine arms, each ending in a jump to a shared decrement/backedge, is recognized from ordinary instructions. The arms may have different lengths and arbitrary bounded sequences of invariant-register additions and multiplications (up to the recognizer's span limits). The selector must be a contiguous low-bit mask <=4095 and the decrement must be -1 modulo 2^32. Three mutable registers (state, scratch, counter) are distinct from invariant operands. This is a guarded structural recognizer, not arbitrary CFG analysis. Effects, malformed instructions, aliasing and unsupported masks/decrements remain conventional. Existing equal-length loops remain supported.

The symbolic arm maps T_p are obtained by ordered affine composition. The selector p=x mod m is closed because m divides 2^32. Assign each selector a positive weight l(p)=6+number of arm operations, the number of logical instructions in its complete iteration. Discover only the reachable selector prefix and cycle; accumulated weights form a strictly increasing prefix sum. Whole cycles can be selected by integer division of remaining time and iteration count by cycle duration and length. Then select the remaining complete iterations by scanning the cycle prefix. Realize their ordered affine composition using path_run, preserving the last pre-transition residue as scratch. Any remaining partial iteration is executed instruction by instruction, so PC and all registers are exact at any budget boundary. Counter zero means 2^32 iterations. The fixed-width operation bound is O(min(m,n)+log n) excluding bounded recognition/validation; the charged work includes table size, symbolic arm operations, weighted discovery, tail selection and path realization, but not wall time or failed attempts. Fallback is available when optimization is not admitted or profitable by the conservative heuristic.
