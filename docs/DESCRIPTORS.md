# K3.2.1 — Resource identity and observer-local descriptors

RVFS contains shared file objects and a pool of 38 open descriptions; RVFds contains 19 local slots and independent close-on-exec flags. Each open description owns an offset, access/append mode and reference count. dup(23), dup3(24), fcntl(25) and statx(291) expose bounded RV32 Linux-number subsets. Separate opens have independent positions; duplicates share positions and append flags. Closing a descriptor drops only its reference. Duplicated standard streams retain their original stream identity. statx emits a zero-initialized 256-byte wire record with only supported fields. No full POSIX conformance, execve, general process scheduler, Unix permission or stable inode identity across deletion/restart is claimed.

The descriptor probe compiled the same C source for native and RV32 execution and matched output and exact persisted file bytes. A native harness executed two independent compiled guest contexts in 55 alternating bounded scheduling rounds, shared file objects across descriptor tables, checked unlink restrictions and released all references. Existing filesystem and runtime regressions passed in the preceding local pass. Actual bare-metal boot remains unverified; QEMU unavailable locally. The next storage refactoring keeps the descriptor/open-description boundary stable while introducing exact alternative byte representations.
