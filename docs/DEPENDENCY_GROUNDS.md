# C0.12 — Multidimensional dependency Grounds

A source-qualified observer-specific extension of layered contraction. All four u32 registers participate. A host-level selector reads the four parity bits, choosing one of 16 declared register programs. Every program contains 1..64 admitted WASM instructions: set, copy, add, mul, addr, mulr. The intention requests a nonempty unique ordered subset of registers and their low b bits, 1<=b<=32, at a u64 time. This uses the original WASM reference and shared realization dispatcher. No new external module imports. This is not a Linux instruction-region compiler.

## Precision-transfer law

Given two states with equal parity vector and agreement bounds k_j>=1, construct a 4x4 capped min-plus dependency matrix M. Each output satisfies k'_i >= min(32,min_j(M_ij+k_j)). An absent dependency is encoded as 32. Initially M is the identity (0 diagonal, 32 elsewhere). Constant assignment clears a row; copy takes the source row; literal addition preserves it; literal multiplication shifts by v2(literal), saturated; distinct-register addition takes componentwise min; self-add shifts by one. Self-square shifts by at least one because x+y is even. For distinct register products use xy-x'y'=(x-x')y+x'(y-y'), so shift the destination row by 1 if the source is even, and the source row by 1 if the destination is even, then take their min. Track parity after each instruction. These rules prove conservative lower bounds under the declared modular integer algebra, not exact valuations or a proof of machine implementation.

The 16-state selector graph is compiled and its successors checked by independent BigInt instruction semantics. For each selector orbit, find tail d and period p. Compare states at d and d+p, which share parity. Initialize agreement vector (1,1,1,1), then propagate around each selector cycle. The cycle map is monotone on the finite lattice [1,32]^4 and its first iterate dominates the bottom vector. There can be at most 124 strict increases before stabilization. At the first cycle j at which the requested register bounds reach b at every phase, set S=d+j*p. Monotonicity preserves this at every later phase. Thus the requested projected observations agree between times t and t+p for t>=S even if unrequested registers do not repeat. For n>=S reduce to S+(n-S) mod p; for n<S retain n. If the precision fixed point cannot certify the observation, refuse this method. Not a proof that the actual system is nonperiodic or impossible to navigate.

The source identity binds exact ordered programs, projection width and target order. No exhaustive 2^128 table, no persisted atlas yet; each request reconstructs its small proof plan. Admission checks reduced execution using a separate BigInt interpreter but shares the structural bound computation. Cost reservation is 2*t*max layer length+5, or 2*n*max layer length+1 for conventional reference within one million source-work units, plus dispatcher probe charges. Plan construction, hashing and other overhead are not included; no measured speed or hard-resource bound. Intent factory freezes the nested source arrays. No side effects, arbitrary register algebra or whole-machine state claim.

## Local evidence

Node 22 with actual original WASM: four program families, all 16 selectors; 4096 conservative agreement relations on paired high-bit states; 512 moderate differential observations; 64 additional 160-step WASM trajectories; 192 near-max-u64 independent cycle-oracle comparisons with zero WASM calls during these requests; 64 large-coordinate refusals and an additional full-state refusal. In swap-and-square with independent incrementing fourth register, observed registers 0,1,2 qualify with S=62..63, period 2; full-state contraction refuses. The independent oracle tracks the observed three registers and parity of the fourth, a closed projection for this particular test. Alternating swap and swap-square contracts one lane but leaves a zero-gain dependency in the other, so the conservative compiler refuses all starting selectors for the three-register projection. Coupled addition/multiplication family qualifies full state with S=32..34, period 1; distinct product family S=31..33, period 1. Invalid duplicate target and an injected false result on a qualified swap-and-square path refused; the trace explicitly records admission-refused. Regression: scalar layered 640 moderate/288 huge/224 refusals/160 WASM/1152 finite/64 projection, affine dispatcher and nonlinear atlas tests passed. No full kernel regression, controlled benchmark or actual Linux guest qualification.
