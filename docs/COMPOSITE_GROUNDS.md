Reuses the actual C0.12 dependencyIntention, compileDependencies, dependencyBindings, and common realization dispatcher. New original VL-K code combines separately admitted output projections, not a general nonlinear solver. All C0.12 source restrictions remain: 16 parity-selected layers over four modular u32 registers, low-bit observation and u64 horizon.

## Phase-aligned composition

For initial selector tail d and cycle length p, if n>=d let h=d+(n-d) mod p and q=(n-h)/p. Execute h source layers to reach the phase of the required output; let F be the ordered p-layer composition starting at that phase. Then T^n(x)=F^q(T^h(x)). If n<d execute n steps and take q=0. Parity closure is established by the previous source-qualified compiler.

The contraction method compares the phase-aligned state after h steps to the one after h+p steps. Propagate capped min-plus agreement vectors around F starting with all ones, up to the fixed point or 124 strict increases. If register r reaches the required width after j cycles, that register agrees between successive F iterates from j onward, by monotonicity. Therefore its exact projected value at q equals its value at min(q,j). The earlier all-phase contraction check was sufficient but unnecessarily restrictive for this intention. No assertion that other phases of the same register contract.

For residual registers, symbolically compose F in the modular affine algebra (four coefficients plus constant). A nonlinear row becomes unknown unless an admitted constant operation restores an exact affine row. Select a closed subset by removing any affine row depending on a removed/unknown row until stable. For this subset apply homogeneous matrix power F^q. Dependencies can cross lanes within a phase cycle; closure is on the composed cycle, not each individual layer. If any required register has neither a contraction bound nor a closed affine law, the composite candidate is ineligible. Conventional and dependency-only methods remain in the dispatcher; no partial observation admitted as complete.

## Admission

The separate checker expands the cycle as bounded sparse polynomials in four variables modulo 2^32, rather than relying on the builder's affine abstract interpretation. It rejects or discards over-limit rows (128 retained terms, 4096 pair products, exponent cap 64). It extracts exact affine rows, checks closed dependencies, and powers substitutions rather than a homogeneous matrix. Contracting components are computed with the existing precision proof and independent BigInt execution. The checker shares the phase and agreement-bound construction; not a fully independent formal proof of the compiler or hardware. All requested values must match in the caller's target order. Candidate cost is a conservative declared policy reservation of 12800 units plus twice the bounded layer work at maximum program length; not a measured or hard execution budget. Preparation, repeated discovery and symbolic checking may be expensive. No persistent composite atlas, mutable effects, machine snapshots or arbitrary source instructions.
