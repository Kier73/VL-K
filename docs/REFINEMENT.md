# K2.11 — Constructive refinement of temporal exceptions

## Synthesis and admission

A power-of-two residue table of size m<=4096 describes a u32 state transition a_p*x+b_p and positive integer weight w_p for p=x mod m. Rather than choose one of the original coefficient pairs, synthesize a candidate global affine map from its uniquely necessary values at x=0 and x=1: B=b_0 and A=a_1+b_1-B modulo 2^32 (m=1 uses its only row). For each row, require (a_p-A)*p+b_p-B=0 and (a_p-A)*m=0 modulo 2^32. These conditions are necessary and sufficient on the residue class by substituting x=p+m*k. If either condition fails, report an actual differing x=p or p+m, actual and candidate outputs, and use the exact previous weighted representation. If A is not 1, the new sparse-clock construction is not admitted, even though a global affine map exists.

For a translation x'=x+B, factor weight w(p) into a modal positive default W and a finite list of deviations (p,w_p). Admit this representation when exception count e<=floor(m/8); the threshold is a heuristic, not a theorem about optimal cost. The global law is proved by exhaustive row checks, not by sampled traces. The table input is scanned at construction; the realized sparse representation retains no dense table. Dense and nontranslation cases fall back to discover_weighted.

## Exact observation without orbit enumeration

Let g=gcd(B,m), L=m/g. From x, exceptional residue p is reachable iff g divides (p-x) mod m. For a reachable exception, its first occurrence offset j in [0,L) is ((p-x)/g)*(B/g)^(-1) mod L, with differences reduced modulo m and L=1 handled explicitly. Each reachable exception occurs once per period. Sort event offsets; their completed end times are W*j plus preceding deviations plus w_p. Positive weights make ends strictly increasing. Prefix deviations give period duration D=W*L+sum(w_p-W) over reachable events. Divide the requested time by D, binary-search the completed exceptions in the remainder, and realize the remaining default steps capped at the next incomplete exceptional offset. Apply the requested iteration cap; reconstruct elapsed time by period division and rank of exceptional offsets. Realize x+n*B mod 2^32 and last pre-transition residue (or None when n=0).

This preserves complete-iteration state, count, elapsed time and last original selector, not every internal instruction state. The ordinary guest's special case recognizes equal translation maps with one zero-residue duration exception; it uses the sparse clock directly and executes residual instructions conventionally. A conservative small-count cutoff and work budget allow ordinary fallback. Setup charges count arm operations; sparse work counts gcd/inverse, event visits, binary-search comparisons and final arithmetic groups, not sort comparisons, validation, Python overhead or physical time. Worst-case per query O(e log(e+1)+log m) bounded-word operations including modular inverse, with O(e) space and no scan of the selector period. Construction is O(m) for the admitted sparse case. Refused cases may pay the earlier weighted quotient search. No general affine-orbit discrete-log solution or global complexity claim.

## Use and evidence

vlk refine TABLE accepts a weighted JSON table of [a,b,w] rows. It reports the admitted method, check count, reason, optional witness and sparse exception count; then responds to newline JSON x (u32), ticks and maximum (canonical decimal u64 strings). Returns final x, completed iterations, elapsed, last original residue and work. Trusted local research interface; input lines are not independently size-capped.

## Research direction

The prior failed weighted representative quotient gave the structure of its own repair: separate the state law from the exceptional clock. A sparse exception count is not sufficient on its own; the occurrence positions must also be navigable. Generalize from translations to broader affine or layered selector paths by solving their exceptional visit coordinates, or retain the finite cycle when cost/admission fails. A candidate failure witness is actionable evidence about representation mismatch, not a proof of universal irreducibility. Compare total discovery, verification and repeated observation costs when selecting among representation families; the present threshold is deliberately simple. Conventional executable compatibility and complete E-CPU runtime integration remain open production tracks.
