# C0.10 — Finite coordinate navigation

The original GroundAtlas admission and serialized transition law remain unchanged. Replace its 64-level jump index with a functional graph coordinate compiler. This is an original VL-K implementation of established finite graph and binary lifting algorithms; it is not a new general complexity theorem. Prior cross-repository survey informs the observer-projection and admission separation; no new external code is imported in this pass.

For a complete deterministic transition T on N<=4096 states, peel indegree-zero vertices, enumerate each cycle, then traverse the peeled order in reverse. Each vertex x has a cycle ID c(x), entry position p(x), and tail distance d(x). Independently check local equations: if d(x)>0, d(T(x))=d(x)-1, c and p agree; if d(x)=0, x is the cycle member at p, and its successor is the next member modulo cycle length. A bounded tail jump index is compiled and its composition law checked. The trusted source table is admitted independently by GroundAtlas before index construction.

If t>=d(x), select cycle member (p(x)+((t-d(x)) mod cycle length)) mod cycle length. This is a constant number of bounded-width arithmetic/index operations for u64 time, not constant bit complexity for arbitrarily long integers. If t<d(x), use binary jumps with levels only up to ceil(log2(maxDepth)) (zero levels for maxDepth<=1). Construction and typed index storage O(N*(1+log(max(1,maxDepth)))); tail selection O(log(max(1,maxDepth))); no dependence on iteration count after cycle entry other than arithmetic width. The index arrays are private, and query admission recomputes selection from the checked index, not an independent query proof. Persistence rechecks the complete table against source semantics and rebuilds the index. The old table remains on disk (same JSON size). No fsync, authentication, crash-durable publication, multiwriter or automatic discovery claim.
