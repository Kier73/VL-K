# K2.4 — Automatic path extraction

An ordinary guest loop can be lifted without a repeat instruction or annotations. The recognizer admits an exact eleven-instruction layout: mov scratch,state; and scratch,mask; jnz scratch,branch1; two equal-length mul/add/jmp branches; add counter,decrement; jnz counter,header. Three modified registers must be distinct and disjoint from all invariant operand registers. Both paths execute eight instructions. The runtime guard requires a contiguous low-bit mask (at most 4095) and decrement 0xffffffff. This is a specialized structural recognizer, not a general control-flow compiler. Guest mode reference disables automatic lifting; auto and ground may lift when profitable and fall back otherwise. The new and opcode is ordinary u32 bitwise AND.

The mask projects the full state into a closed residue quotient. The ordered branch maps are affine over u32; the existing path evaluator discovers and powers their cycle. Preserve the scratch register by navigating n-1 transitions and explicitly applying the last selected map. Counter zero at entry means 2^32 iterations (do-while semantics), not zero. The number of complete iterations navigated is min(counter-or-2^32, remaining logical budget / 8). The final backedge or fallthrough and all registers are preserved. Partial iterations execute normally, so changing the scheduling quantum cannot change the observable state. Effectful or malformed loops are not lifted. Optimization work is accounted separately; the charge includes selector table construction and last application, not recognition, validation, dispatch or unsuccessful attempts. Budget refusal falls back to reference execution. This is not a security resource meter.

## Evidence

Local independent suite: 500 randomized programs; 2226 matching budget checkpoints (pc, all registers, halt state, exit and stdout); 1406464 logical instructions lifted; independent scalar recurrence oracle. A zero-counter loop with 4294967296 iterations navigated 34359738368 logical instructions, followed by two ordinary dispatches, in 69 charged path units, matching an independent modular closed form. Irregular masks, decrement changes, register alias, effectful paths and exhausted optimization budget all fell back and matched reference. The complete clean managed self-build passed the first 12 suites and timed out during the 13th; the 13th passed separately before that run. Remote CI independent.

The benchmark uses the actual native launcher and guest CLI through Supervisor, alternates mode order, checks stdout against a separate closed form and requires matching exit/stderr. 200000 iterations, 1600009 logical instructions. Three runs per mode, median reference 3.220632 s, auto 1.535699 s (2.10x local end-to-end), including startup and capture. Output 00. This is not superiority over native optimized code; the program is hosted Python guest code. Reproduce with make all then python3 benchmarks/guest_lift.py.

## Implication for Layered Path Ground

A closed selector projection is necessary for this specific construction; efficient ordered composition and correct reconstruction of every observed register and interruption coordinate are also required. Equal-length branches make logical time navigation trivial. Unequal-length paths need weighted selector orbits and rank/select over prefix costs. Effectful loops need effect-preserving observation boundaries, not final-state equality alone. Next: derive branch transformations symbolically rather than recognize one layout, extend to weighted and nested selectors, and measure rejected-loop overhead. Conventional executable loading, syscalls and terminal functionality remain parallel production goals.
