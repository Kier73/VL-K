# C0.8 — Shared computational realization

A pure intention is a domain-qualified, receiver-validated request. Each locally bound candidate supplies probe, run, and admit functions. Discovery admits eligibility and a positive integer declared reservation (or null for ineligible); selection sorts by reservation, preserving original order for ties; execution proposes a result; admission returns the value or throws. Refusal is explicit. All attempted candidates are charged their reservation including failed candidates, plus one unit per probe. A request unable to afford all probes refuses before probing. Up to 16 candidates. Receipt records the intention, selected binding, declared budget, charges, refusal/selection trace and measured discovery, realization, admission and total wall milliseconds. It is a local execution record, not a signed proof or globally unique identity.

Budget units are domain-specific policy estimates, not metered resource consumption or a wall-clock limit. Sorting, callback setup, output materialization, and external work are not separately metered by the budget. Phase timing includes callback waiting; total includes dispatch overhead. Bindings and cost declarations are trusted receiver-owned code. Domain factories validate and freeze the data they use; dispatcher only checks the top-level freeze, not a general deep immutable input, trust boundary or authorization mechanism. No cancellation, deadline, scheduling of mutating effects, learned costs or global optimality. Greedy lowest declared cost among eligible candidates may be worse than another ordering under failure. A candidate must be safe to reject; no arbitrary effects or rollback guarantee.

## Temporal domain

vlk.affine-u32.v1 observes x_n for x_(t+1)=a*x_t+b mod 2^32 and a u64 coordinate. Both candidate bindings invoke the unchanged original js/vlk.mjs import-free WASM nucleus, explicitly selecting its reference or affine matrix Ground mode. Two instructions per reference iteration. Ground work declaration follows existing C matrix cost: 10 setup, 25 per set bit and 125 per required square for nonzero n. Add a declared verification allowance of 1+3*bit_length(n). A candidate over one million modeled execution-work units is ineligible. The WASM engine receives the reserved budget and retains its own budget check. A separate JS BigInt scalar affine power implementation admits the exact result and unchanged other registers. This checks mathematical output independently of C execution but is another logarithmic computation, not an inexpensive universal certificate. No novel complexity bound for affine exponentiation. Scalar affine only, not Linux instruction blocks or nonlinear general execution.

## Storage domain

vlk.block-observation.v1 uses the existing admitted immutable receipt and page coordinate. Derived zero ranges and admitted cached bytes are receiver-owned state; new pathway proposals use the existing independent coordinate verifier. Reservations 1 for zero, 2 for cache, 3+j for ordered routes; these are priority/attempt policy units rather than comparable physical work. Per-page budget 65 covers probes and attempts across at most eight routes. Existing read-only ABI, complete-read output staging, path and zero evidence, and TLS checks retained. realizationCosts() accumulates phase and total times and declared charges across page requests (concurrent times may overlap). Cache capacity remains bounded.
