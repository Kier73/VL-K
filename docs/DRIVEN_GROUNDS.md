# C0.14 — Driven computational Grounds

Source-qualified phase specialization of interacting nonlinear systems. Uses the actual C0.12 dependency compiler and C0.13 composite dispatcher with no new external dependency. All existing source, selector and u64 restrictions remain. No arbitrary program or Linux execution claim.

## Construction

For source T, initial seed and requested time n, choose h=tail+(n-tail) mod p on the qualified 16-state parity selector path, where p is the cycle length. If n<tail the method is ineligible. Write n=h+qp. Let F be the composed cycle at that phase. Starting with agreement vector all ones, apply the capped min-plus cycle law until a fixed point or 124 iterations. Its monotone iteration certifies a nondecreasing lower bound on agreement of successive cycle states. Select full-width (32-bit) stable coordinates D at iteration j. If none exist or q<=j, the method is ineligible. Execute prefix h+jp exactly, retaining the seed z at that boundary. For each i in D the coordinate of every subsequent F iterate on this trajectory equals z_i, by the existing precision-transfer proof. This assertion is phase-specific and trajectory-specific; it does not assert global invariance or that intermediate instructions cannot change these coordinates.

Specialize the input of F on those proven constants and symbolically compose the actual instructions. This can convert products of a driver with a changing dependent into exact affine expressions. At cycle boundaries reset proven driver rows to their certified constants. Remove unknown/nonaffine rows and affine rows depending on them until closed. If any requested coordinate is not in the closed set, refuse. Apply homogeneous matrix power for q-j cycles to the prefix state; project the required bits in requested order. All transient influence is preserved by the exact prefix. Fixed width is deliberately required even when the requested projection is narrower.

The independent checker uses BigInt prefix execution, bounded sparse polynomial expansion (128 retained terms, 4096 pair products, exponent cap 9) and affine substitution powers. It shares the precision/phase proof and closed-subspace procedure, and does not constitute independent formal verification of the source instruction semantics. No silent polynomial approximation or partial-output admission. The new binding is appended to the actual composite dispatcher; older candidates remain unchanged. Cost reservation is 25000 plus twice prefix*maximum layer width. This is a declared selection policy, not a hard work or wall-time limit; setup and repeated geometry/proof computation are not fully charged. The index is not persisted. No general asymptotic acceleration result, controlled speed benchmark, arbitrary nonlinear residual solver, mutable effects or distributed state qualification.
